# Как работает PrReviewWorker в doWork()
Получает идентификатор Pr

1. Стартует сначала AIAgent с промптом, в котором указано извлечь из Pr список файлов, название и текста описания.
 Вернуть в Json
 Его цель собрать данные для последующих агентов.
 
2. Далее по количеству файлов в цикле вызываем (пересоздаем) AIAgent с промтом (пример - надо причесать):
  провести ревью кода одного файла
  можешь использовать инструменты для поиска по кодовой базе проекта (у нас есть инструмент "search_codebase")
  можешь запрашивать из гит список файлов проекта (у нас есть "get_git_file_list") (МОЖЕМ ЛИ МЫ завести аналог "get_git_file_list" стобы агент мог запрашивать не все файлы а по шаблону??? ) 
  можешь получать контент файлов из git ("get_file_content") если они необходимы
  можешь получать diff файл (нуужно завести tool)
  Если видишь потенциальные баги или архитектурные проблемы оставь комментарий у файла в PR с помощью интсрумента (нужно завести tool)

  Независимо от результатов вызова инструментов проведи анализ изменений и выдай отчет:
  - потенциальные баги
  - архитектурные проблемы
  - рекомендации
  - и описание того, что ты сделал
4. Все агенты по очереди отработают (с ошибкой или без все равно) - мы стопочкой сложим результат и отправим в чат (просто сохраним в БД сообщение типа Bot).

5. Можно добавить агента, чтобы он по результатам работы предыдущих написал короткое резюме
  - потенциальные баги
  - архитектурные проблемы
  - рекомендации


В результате будет:
