# Реализация

## Новый тип чата и AssistantWorker
Заведем новый типа чата  ChatType.ASSISTANT  (см. пример ChatType.RAG_CONTEXT)
В этом типе чатов за обработку команд из консоли отвечает новый класс AssistantWorker (см. пример RagWorker)
Заведем AssistantTalkDelegate  (см. пример RagTalkDelegate)

Нужна вся инфраструктура для создания нового типа чатов и перехода в него:
 1) Создание в ChatsScreen.kt, метод ChatsScreenInternal()
 2) DI в FeatureEntryProvider:
    @Stable
    fun getAssistantConsoleFeatureEntry(): AssistantConsoleFeatureEntry
 3) Интерфейс AssistantConsoleFeatureEntry (пример RagConsoleFeatureEntry)
 4) AssistantConsoleFeatureEntryImpl (см. пример RagConsoleFeatureEntryImpl)
 5) Изменения в ConsoleFetureComponent:
   fun getAssistantViewModelFactory(): ConsoleViewModelImpl.AssistantFactory
 6) AssistantFactory в ConsoleViewModelImpl
 7) AssistantTalkDelegate (см. пример RagTalkDelegate)

Предусмотрен возможность исопльзования ConsumptionCalculator для подсчета статистики запросов и вывода их в чат по аналогии с AgMessageHandler.

## Команда @@help 

AssistantWorker в методе doWork() предположительно первым делом будет проверять, не начинается ли ввод ввод пользователся с @@help.
Если да - то в AIAgent будет добавляться
```
 val ragContextProvider = ragContextMemoryProviderFactory.create(agentId)
```
аналогично RagWorker.
Иначе - нет.

## Остальные подробности AssistantWorker
Аналог RagWorker но 
1) const val AGENT_NAME = "assitant_agent"
2) SYSTEM_PROMPT = """Твоя задача помогать пользователю разобираться с кодовой базой проекта. Ты можешь использовать инструменты чтобы заправшивать контекст по вопросам пользователя у RAG базы данных по проекту, а также можешь использовать инструменты для работы с git"""
3) private const val MSG_LIMIT = 8
   private const val EXTRA_LIMIT = 8
4) saveTestResults() - не будет
5) Системный промпт должен настраиваться способом как у JustWorkWorker
6) Подключение к агенту Mcp. Для этого надо подключить AgentToolsMemoryProvider.
Пример подключения смотри в JustWorkWorker - надо полностью скопировать onCreateCallback у их агента, чтобы появилась возможность работы с McpTools и SystemPrompt
allowedTools - проверять не надо - пусть будут доступны все зарегистрированные.
