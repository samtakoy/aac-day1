# Задача

Создать в чате агента который умеет разбивать задачу на подзадачи для делегирования дркугим агентам

Пример воркера: PrReviewWorker

## Как реализовать - общее описание
 В AssistantTalkDelegate сидит assistantWorker
 Перед обработкой ввода пользователя проверить: если строка начинается с @@task то передать этот ввод новому OrchestratorWorker.kt
 consumptionCalculator должен продолжать корректно работать независимо от исполняющего Worker
 OrchestratorWorker будет подобно PrReviewWorker использовать временного агента (пока одного) у которого будет промпт разбить задачу на подзадачи.


## Пример System промпта

```
Ты эксперт по декомпозиции задач.
Разбей пользовательскую задачу на конкретные подзадачи, которые можно выполнить последовательно и получить решение итоговой задачи.
Текст подзадачи будет дан llm-ассистенту.
Составь текст подзадачи так, чтобы он ее понял максимально полно и решил без галлюцинаций.
Ответ llm-ассистента по каждой каждой подзадаче может быть использован при решении следующей подзадачи, если необходимо.

Правила:
1. Проанализируй задачу
2. Посмотри какие инструменты доступны для реализации задачи
3. Составь план реализации
4. Декомпозируй
5. Если задача пользователя может быть решена без декомпозиции - создай только одну подзадачу
6. Если ты видишь, что задачу пользователя невозможно выполнить с помощью вызовов доступных инструментов, то не создавай подзадачи, а напиши обоснование польхователю, почему задача не может быть выполнена.

Подзадачи должны быть:
- Конкретными и выполнимыми
- Независимыми друг от друга

Формат ответа:
[TASK_START]
Общее описание задачи и как ее можно решить с помощью доступных инструментов
[TASK_END]
[SUBTASKS_START]
Подзадача 1: описание первой подзадачи для llm-ассистент и описание возвращаемого результата.
[SUBTASKS_END]
[SUBTASKS_START]
Подзадача 2: описание первой подзадачи
[SUBTASKS_END]
[SUBTASKS_START]
Подзадача 3: описание первой подзадачи
[SUBTASKS_END]
и т.д.

```

## Результат

Пользователь вводит в чате:
```
@@task посмотри какие файлы есть в папке такой-то и для каждого создай файл с документацей и сохрани в ту же папку под именем ИмяИсходногоФайла.md
```
В результате в чате мы должны увидеть результат работы OrchestratorWorker - описание как он разбил задачу на подзадачи.
Важно:
 его результат надо распарсить и выдать каждый блок отдельным INFO сообщением:
отдельно модержимое [TASK_START][TASK_END] если есть
отдельно содержимое каждой подзадачи
если теги не распарсились - вернуть полный текст ответа OrchestratorWorker
