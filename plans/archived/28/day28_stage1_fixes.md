# Этап 1. Фиксы и переименование

## Описание
Минимальные изолированные изменения: исправление опечаток в тестовых вопросах и переименование консольной команды.

## Задачи

### 1.1 Исправить опечатки в TestQueries.kt

Файл: `app/src/.../memory/domain/provider/rag/TestQueries.kt`

| Строка | Было | Стало |
|--------|------|-------|
| Q6 | `"механизм÷ user in the loop"` | `"как реализован механизм user in the loop"` |
| Q7 | `"сколько слоев используют в"` | `"сколько слоев используют"` |
| Q12 | `"state managment"` | `"state management"` |

Также проверить и убрать лишние пробелы в Q16, Q21, Q22 (trailing spaces).

### 1.2 Переименовать команду debuginfo → @@debuginfo

Файл: `app/src/.../delegates/RagTalkDelegate.kt`

- Изменить проверку: `inputText.trim().equals("debuginfo", ignoreCase = true)` → `inputText.trim() == "@@debuginfo"`

---

## Резюме

**Что получим:** чистые тестовые вопросы без опечаток, консистентный стиль команд с префиксом `@@`.

**Критерии успеха:**
- Текст Q6, Q7, Q12 в TestQueries.kt исправлен
- Команда `debuginfo` в чате больше не срабатывает; `@@debuginfo` — работает
- Никаких других изменений в поведении

---

## Подробный план реализации

### Шаг 1. TestQueries.kt — исправить 3 строки

```
Q6:  "как реализован механизм user in the loop"
Q7:  "как агенты работают с памятью и сколько слоев используют"
Q12: "как реализован state management"
```
Убрать trailing пробелы в Q16, Q21, Q22 (если есть).

### Шаг 2. RagTalkDelegate.kt — изменить одну проверку

Заменить условие с `"debuginfo"` на `"@@debuginfo"` (без ignoreCase — команда теперь точная).

### Шаг 3. Проверка вручную

1. Открыть RAG_CONTEXT чат
2. Ввести `@@debuginfo` → должно вывести info-сообщение с debug info
3. Ввести `debuginfo` → должно уйти как обычный вопрос в RagWorker
