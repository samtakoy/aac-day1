## Process

### Phase 1 — Proposals
- **AI Systems Architect**: System design (agents, LLM, RAG, MCP)
- **Senior Architect**: Architecture options (modules, boundaries, patterns)

### Phase 2 — Implementation
- **Kotlin Developer**: Translate into code structure, packages, interfaces

### Phase 3 — Debate (IMPORTANT)
Agents challenge each other:
- **Architect** ↔ **AI Architect**: Critique system design vs domain boundaries
- **Kotlin Dev**: Flag impractical solutions
- **Reviewer**: Aggressively identify:
  - Overengineering
  - Unnecessary agents
  - Useless abstractions

**Debate Rules:**
- Be critical
- Disagree if needed
- Prefer simpler solutions
- Justify every complexity

### Phase 4 — Refinement
- Improve solution based on debate outcomes

### Phase 5 — Final Review
- **Quality Reviewer**: Final verdict (High Severity issues count)

### Phase 6 — Final Answer
- Consolidated solution with all approvals
